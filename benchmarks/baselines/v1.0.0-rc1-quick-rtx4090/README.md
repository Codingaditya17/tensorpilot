# Baseline: TensorPilot v1.0.0-rc1-1 quick session on one RTX 4090 (serial vs continuous batching, 0.5B)

Immutable evidence from the first GPU session of the v1.0 line (2026-10-26): the serial worker and the CUDA continuous-batching worker on
Qwen2.5-0.5B-Instruct (fp16), one repeat per point, plus a 32-prompt batch-invariance check. The quick gate passed (`quick-verdict.json`):
batched c=8 was 5.42× serial c=8 (284.6 vs 52.5 tok/s), batched c=1 was 0.93× serial c=1, no failed request, memory gate passed.

- `serial.tar.gz` and `batch.tar.gz` are the archives exactly as exported from the Pod; the `.sha256` files are their checksums.
- `quick-verdict.json` is the output of `tensorpilot.quick_compare` on those two stages.
- `summary.json` was generated by reading the archives (`tests/test_baseline_quick.py` regenerates and compares it).

Do not edit or replace these files. The analysis of what they show and do not show, including the 31/32 exact-match discrepancy and the
flat 20 ms decode step at 18–22% GPU utilization, is in [`docs/v10-production-evaluation.md`](../../../docs/v10-production-evaluation.md) §1–2.
To reproduce the engine-profile table: extract both archives into one directory and run `python -m tensorpilot.report_v10 DIR --output out`.
